# Nova — AI product landing page

A static marketing landing page for "Nova", a fictional AI workspace product.
Built with plain HTML/CSS/JS and served by a minimal Express static server.

## Running

```bash
npm install
npm start
```

Then open http://localhost:3000.

## Structure

- `public/index.html` — page markup (hero, features, how-it-works, pricing, FAQ, CTA)
- `public/style.css` — styling and responsive layout
- `public/script.js` — mobile nav toggle, scroll-reveal animation, signup form validation
- `server.js` — serves the `public/` directory
